Simulateur de réseau LoRaWAN

Saisissez votre jeton, puis choisissez un mode. Le mode reste changeable ensuite, depuis la barre du haut.

Le serveur n'a pas fourni de jeton. Pour en créer un, lancez sur la machine qui héberge l'API :
python -m lsim.api_server issue-token --tokens FICHIER --owner NOM
Ou relancez l'API avec --auto-token NOM pour que la saisie disparaisse.
